  # Security Policy

  ## Supported Versions

  Database Backup Utility is a small, actively developed project. Only the
  latest released version receives security fixes; please upgrade before
  reporting an issue if you're on an older one.

  | Version | Supported          |
  | ------- | ------------------ |
  | 3.x.x   | :white_check_mark: |
  | 2.x.x   | :x:                |

  ## Reporting a Vulnerability

  If you discover a security vulnerability, please [open an
  issue](../../issues/new) in this repository.

  Please include as much detail as possible: steps to reproduce, affected
  version, and potential impact.

  You can expect an initial response within **5 business days**. If the
  vulnerability is confirmed, a fix will be prioritized and a new release
  will be published, with credit given to the reporter (unless you prefer to
  remain anonymous). If declined, you'll receive an explanation of why it
  was not considered a security issue.
